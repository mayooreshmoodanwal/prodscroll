# Shared implementation contract

Base REST URL http://localhost:4000/api. Web http://localhost:3000. Browser uses credentialed cookies with Origin checked on mutating requests. Mobile uses Bearer accessToken + rotating refreshToken. JSON errors {error:{code,message,requestId}}. Dates ISO strings. List shape {items,nextCursor,hasMore}. Domain ids strings. Root will install dependencies after all package manifests exist.

Public payloads:
User {id,username,displayName,bio?,avatarUrl?,role:'USER'|'FOUNDER'|'MODERATOR'|'ADMIN',onboarded:boolean,verified:boolean, interests?:string[], followerCount?:number,followingCount?:number,postCount?:number,following?:boolean}
Startup {id,slug,name,pitch,description?,logoUrl?,coverUrl?,category,website?,location?,foundingYear?,verified:boolean,followerCount:number,following?:boolean,ownerId,products?:Product[],posts?:Post[],team?:User[]}
Product {id,slug,name,description,website?,imageUrl?,status,category,startup:Startup}
Post {id,kind:'POST'|'REEL'|'UPDATE'|'LAUNCH',caption,createdAt,author:User,startup?:Startup|null,product?:Product|null,media:Media[],tags:string[],likeCount:number,commentCount:number,saveCount:number,liked:boolean,saved:boolean}
Media {id,mediaType:'IMAGE'|'VIDEO',url,thumbnailUrl?,mimeType?,processingStatus:'PENDING'|'PROCESSING'|'READY'|'FAILED',width?,height?,durationMs?}
Comment {id,body,createdAt,author:User,parentId?,likeCount:number,replies?:Comment[]}
Conversation {id,title?,members:User[],lastMessage?:Message,unreadCount:number,isRequest?:boolean}
Message {id,conversationId,sender:User,body,createdAt,readBy:string[],sharedPost?:Post,replyToId?,unsent?:boolean}
Notification {id,type,body,createdAt,readAt?,actor?:User,postId?,startupId?}

GET /health (outside /api), /api/health; GET /api/docs OpenAPI UI.
Auth: POST /auth/register {email,username,displayName,password,role?:USER|FOUNDER} => {user, accessToken?,refreshToken?,verificationRequired:true}; POST /auth/login {email,password} => {user,accessToken,refreshToken}; GET /auth/me => {user}; POST /auth/logout; POST /auth/refresh {refreshToken?}; GET /auth/google starts OAuth; POST /auth/verify-email {token}; POST /auth/forgot-password {email}; POST /auth/reset-password {token,password}; GET /auth/sessions => {items}; DELETE /auth/sessions/:id; POST /auth/logout-all. Local Mailpit receives verification/reset links. Web demo login button must call login with documented seed credentials; no automatic synthetic login.
GET /categories => {items:string[]}; PUT /users/me/onboarding {interests:string[3..10]} => {user}; GET /users/:username => {user,posts:Post[],startups:Startup[]}; PATCH /users/me {displayName?,bio?,location?,website?,privateAccount?}; PUT /users/:id/follow {following:boolean} => {following}; POST /users/:id/block; DELETE /users/:id/block.
GET /feed?mode=for-you|following|reels&cursor => page<Post>. GET /explore => {trending:Startup[],newProducts:Product[],founders:User[],categories:string[]}; POST /events {events:[{type,postId?,startupId?,value?}]} => {accepted:number}.
GET /posts/:id => {post}; POST /posts {caption,kind,startupId?,productId?,mediaIds?:string[],tags?:string[],draft?:boolean} => {post}; DELETE /posts/:id; PUT /posts/:id/like {liked:boolean} => {liked,likeCount}; PUT /posts/:id/save {saved:boolean} => {saved,saveCount}; GET /posts/:id/comments?cursor&sort=top|new => page<Comment>; POST /posts/:id/comments {body,parentId?} => {comment}; PATCH /comments/:id {body}; DELETE /comments/:id; PUT /comments/:id/like {liked:boolean}.
GET /saves => page<Post>; GET /collections => {items}; POST /collections {name}; PUT /collections/:id/items {postId,saved:boolean}.
GET /startups/:slug => {startup}; POST /startups {name,slug,pitch,description,category,website?,location?} => {startup}; PATCH /startups/:id (owner/admin); PUT /startups/:id/follow {following:boolean}; POST /startups/:id/products {name,slug,description,category,status,website?} => {product}; GET /products/:slug => {product,posts}; GET /founder/startups => {items:Startup[]}; GET /startups/:id/analytics => operational counts; POST /startups/:id/verification.
GET /search?q&type=all|startups|products|people&category => {startups:Startup[],products:Product[],users:User[]}; GET /search/history => {items}; DELETE /search/history.
GET /conversations => {items:Conversation[]}; POST /conversations {memberIds:string[],title?} => {conversation}; GET /conversations/:id/messages?cursor => page<Message>; POST /conversations/:id/messages {body,sharedPostId?,replyToId?} => {message}; POST /conversations/:id/read; POST /conversations/:id/accept; DELETE /messages/:id?scope=self|everyone. Native WebSocket /api/ws authenticated by cookie or short-lived ticket: POST /auth/ws-ticket => {ticket}; /api/ws?ticket=... . Server event envelope {type:'message'|'read'|'typing'|'notification',conversationId?,message?,userId?,notification?}; client typing {type:'typing',conversationId,typing:boolean}.
GET /notifications => page<Notification>; PUT /notifications/read {ids?:string[]} (omitted=all); GET /notifications/preferences; PUT /notifications/preferences {push:boolean,email:boolean,inApp:boolean}.
POST /media/upload-url {filename,mimeType,size} => {assetId,uploadUrl,method:'PUT',headers}; PUT uploadUrl raw bytes; POST /media/:id/complete => {media}; GET /media/:id => {media}. Local signed uploads stored under MEDIA_DIR and background job; Cloudflare R2 is the production provider with private incoming/processed buckets and signed delivery; local storage is for development. No credentials embedded in UI.
POST /reports {reason,postId?,userId?,details?}; GET /admin/stats; GET /admin/reports => {items}; POST /admin/reports/:id/action {action:'DISMISS'|'REMOVE_CONTENT'|'SUSPEND_USER'|'WARN',note}; GET /admin/audit => {items}; GET /admin/users?q; PATCH /admin/users/:id {suspended?:boolean}; GET /admin/flags; PUT /admin/flags/:key {enabled:boolean}; GET /admin/verifications; POST /admin/verifications/:id {approved:boolean,note?}.
GET /users/me/export; POST /users/me/deactivate; DELETE /users/me {password}.

Use Prisma 6.19.x and Postgres. Keep all implementation files <700 lines when practical. Do not substitute fake in-memory persisted services. Local SMTP/provider alternatives explicit. Use reasonable scope and document any unsupported requirements honestly.
